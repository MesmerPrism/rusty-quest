# Spatial Camera Panel legacy index

This protocol-v2 workspace is an inert index for the archived mixed Camera,
private-downstream, and Spatial VR Strobe integration history. It is not a
current implementation authority and its feature lock selects nothing.

The complete pre-v0.6 workspace is preserved byte-for-byte under
`../legacy-workspaces/mixed-integration-v1/`. Its sorted path-and-file-hash
fingerprint is bound by `legacy-archive.json`.

New private downstream work resumes from that private project's own workspace.
New Spatial VR Strobe work resumes from
`../../spatial-vr-strobe-android/morphospace/`. Public Camera adapter changes
must be governed by the consuming project or a bounded Rusty Quest unit.

Do not rewrite the archived units or event prefix to make historical vocabulary
look current. The archive contains superseded in-flight records that cannot use
the portable terminal-unit adoption contract.
