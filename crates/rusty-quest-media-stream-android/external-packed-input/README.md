# Instance-owned external packed input

This optional source module receives one external packed RGBA stereo atlas into an app-owned Android ImageReader. It provides the actual Surface, Image and HardwareBuffer ownership seam for an existing GPU consumer. It starts no capture service, operates no device, records no media and grants no vendor/capture/session/Ready authority. It is not wired into any default application or build root.

Compile against the exact external Lab sink inventory in DEPENDENCIES.json. Reuse its existing SinkPublisherOwner for lifecycle accounting. No second lifetime reducer is implemented here. Its internal StereoSinkDescriptor supplies typed storage/accounting; the optional Binder compatibility wrapper preserves the deployed app-owned v2 snapshot wire rather than exposing the neutral19-word wire.

`PackedInputReader.open(processGeneration, descriptor, sharedOwner)` must run on an owned control worker. Initial storage is2560x1280 RGBA_8888, identity top-left SBS; usage768 and maxImages are validated by the existing descriptor. Reuse the same shared owner across replacements and supply a strictly newer actual reader generation after true retirement. OwnedOpenFailure.original retains the exact partially constructed provider; close/reconcile that instance before replacement.

`ownedSurface(exactReaderG)` returns a new separately owned wrapper. Caller must retain/release its own copy around its original capture invocation. `takeLatest(exactReaderG)` returns one acquisition with exact process/reader/token identity, monotonic acquisition sequence and actual positive Image timestamp. The timestamp domain is producer_unverified. This storage contract supplies no optical eye identity, rectilinear tangent/FOV calibration, coverage beyond declared storage, capture pose, clock correlation or dataspace qualification.

On the existing consumer GL actor, call `acquisition.beginCopy(originalCompletionPort)` before borrowing/submitting. The existing sink fence ticket is registered then. `copy.borrowBuffer()` yields the actual HardwareBuffer once; it is borrowed and the caller must not close it. Pass that object to the consumer's existing JNI/GL import, not a raw pointer encoded as a Java long. The original Image AND separately acquired HardwareBuffer remain retained until `copy.pollRetired()` observes the original native copy fence and same-context import teardown through that exact completion port. The port is an injected physical executor, not a caller completion Boolean or timeout. Wrong actor, duplicate borrow, unknown fence/import/close or failed accounting retains original custody; no replay/replacement is supplied. A no-capacity consumer releases only an unsubmitted acquisition.

The bounded latest slot replaces only an unclaimed acquisition. Claimed/copied acquisitions stay owned; the reader's maxImages bounds physical acquisitions. Native ImageReader acquisition can block while waiting for its real producer fence. That original Handler/callback must remain owned; neither timeout, cancellation nor thread replacement is a completion. Source inspection of AOSP Android12 and14 shows the Java native acquire path calls BufferItemConsumer::acquireBuffer with its default waitForFence=true. ACQUISITION_SYNC names this qualified implementation path; RETURNS_ACQUIRE_FENCE_FD=false describes the selected API. No synthetic FD is returned. This is source/API evidence, not a proof of an arbitrary vendor binary, newer/older release or latency bound. Android34 is the compile target; required runtime APIs start at29.

`stopPublishing()` is a nonblocking media gate. It deliberately keeps the sink owner structurally ACTIVE while subsequent real callbacks acquire/close Images with real callback/image tickets to drain a still-stopping producer. It creates no new freshness. Only after the independently owned original producer retirement may its owner call `requestReaderCloseAfterProducerRetired()`. That posts one original Handler seal/barrier, invalidates the sink, detaches the listener and requests that same worker's safe quit. `pollClosed()` requires actual original thread termination/join, every acquired/copy lease released and then real ImageReader.close before readerDestroyed/observeDrained/retire. Unknown post/close outcomes are retained and never retried. There is no vendor retirement ACK and no inspection-duration timer.

`PackedInputPublisherV2(Context, reader)` requires actual Shell UID plus per-call DUMP, synchronous calls, exact positive generation and no trailing request fields. GET_SNAPSHOT writes the fixed v2 version/generation/five-long-array/Surface shape. GET_STATUS is always null/unavailable in this slice: acquired or copied input is not final renderer completion, rawLive, completedValid or Ready. The unchanged diagnostic inspection helper therefore is not this provider's production controller. SET_MODE/effects and arbitrary commands are absent. The app owns any exact manifest/component registration, source switch, no-save policy, actual SDK exclusion, private capture provider and final renderer readiness join.
