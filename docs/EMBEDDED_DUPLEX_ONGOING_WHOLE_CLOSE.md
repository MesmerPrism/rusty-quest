# Ongoing Peer whole-product cleanup projection

The native lifecycle producer emits
`rusty.quest.embedded_duplex.concurrent_peer_lifecycle.v3` when its selected
runtime contains the closed one-field
`rusty.manifold.peer.ongoing_media_policy.v2` policy. Java whole-product
aggregation and the process-owned Activity rollover token recognize that exact
pair. The finite lifecycle v1 and authenticated remote-owner cleanup v1 paths
retain their existing meanings. Lifecycle v2, unknown versions, missing or
different policies, and extra policy fields are not this contract.

Schema recognition supplies no cleanup evidence. Local closure still requires
the native terminal Peer effect, route cleanup and Broker evidence, exact
runtime/app/executor identities, physical Own capture and all resource owners,
renderer/GPU barriers, callback/control retirement and persisted process fence.
The same final whole-product proof binds the opaque rollover token. A pending
barrier cannot clear Activity state or admit a fresh process/runtime. No-media
closure and remote-owner cleanup retain their separate owner proofs.

Whole-product closure does not require current renewal authority to remain
active after Stop. In particular the native receipt's current-owner validation
may truthfully report unavailable. This neither revives credentials nor admits
Start, renew, replacement owners or a callback supplied by a caller.

`tools/checks/Test-WholeCloseActivityRolloverHost.py` compiles the actual token,
local terminal predicate and current-host predicate. It exercises finite and
ongoing shapes, damaged policy/schema and each final physical barrier, plus
the original actor/runtime/attachment and Activity callback guards. Its native
producer source join verifies the v3/policy association and existing native
terminal effect/route predicate. Native/platform/Broker/fence facts remain
explicit models. These tests do not qualify an APK, device, actual cleanup or
ongoing physical streaming; those require separately selected source, artifact
and owner evidence.
