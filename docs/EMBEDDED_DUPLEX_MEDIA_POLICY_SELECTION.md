# Artifact-fixed embedded duplex media policy

The Spatial Camera Panel builder accepts explicit `-EmbeddedDuplexMediaPolicy
finite` (default) or `ongoing-v2`. The value is closed and case sensitive. The
builder scopes and restores its Gradle environment; an ambient value cannot
select policy through this entrypoint. Ongoing selection requires explicit
real-peer product inputs. It enters the native, Android-shell and build-input
identity descriptors before their fingerprints and is projected into the APK
inspection, build manifest and run capsule. Finite descriptors omit the field.

Gradle emits the selected constant in BuildConfig. Actual SessionInputs puts
exactly `{"$schema":"rusty.manifold.peer.ongoing_media_policy.v2"}` into the existing
`embedded_duplex.ongoing_media_policy` field only for a selected concurrent
real-peer route. Finite and local-fixture inputs omit it. Unknown selections and
ongoing without concurrent real-peer owners refuse. The fixed native ABI,
packaged product assets and finite setup-credential issuance/expiry are
unchanged. Selection grants neither a media route nor authority renewal.

This source candidate composes the Camera2 source-graph readiness handshake and
closed bootstrap failure observations with the ongoing history implementation.
The accepted incoming-owner restart fix is retained. It is source-only: an
actual product source/catalog admission, qualified native closure, generated
artifact and product-owned physical validation remain required before adoption.
Java whole-product terminal compatibility is described in
[the ongoing cleanup contract](EMBEDDED_DUPLEX_ONGOING_WHOLE_CLOSE.md).

Affected host controls execute production SessionInputs, credentials and closed
policy code with modeled enrollment/Android JSON/capture facts; closed builder
projection checks preserve finite omission and reject unsupported values. They
are not Android typecheck or device qualification. No timer, wrapper counter,
expiry bypass or implicit reset selects ongoing behavior.
